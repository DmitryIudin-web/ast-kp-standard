# Импорт фотографий из объявления

Утилита `fetch_listing_photos.py` открывает публичное объявление в Chromium, находит видимые и опубликованные на странице изображения, скачивает их в локальный каталог (передавая CDN только origin объявления как `Referer`) и сохраняет `photos.json` с адресами источников и SHA-256.

## Установка

Нужны Python 3.10+ и доступ к публичной странице объявления.

```bash
python -m pip install -r requirements-photo-import.txt
python -m playwright install chromium
```

## Запуск

```bash
python fetch_listing_photos.py "https://example.com/listing/123" --out "./listing-photos"
```

По умолчанию загружается не более 12 изображений, не крупнее 25 МБ каждое; общий лимит — 100 МБ. Лимит количества можно задать через `--max-images 1..30`, тайм-аут — через `--timeout 20`. Каталог результата должен быть пустым, чтобы снимки разных объявлений не смешались.

После загрузки откройте каталог и вручную проверьте, что фотографии действительно показывают нужный автомобиль, а не логотипы, похожие объявления или каталог. Утилита намеренно записывает `identity_verified: false`; она не подтверждает идентичность автомобиля по фото. Выберите проверенные снимки и передайте их в `PHOTO_HERO` и `PHOTO_1`–`PHOTO_5` шаблонов.

## Ограничения и безопасность

- Поддерживается извлечение изображений из HTML, метаданных, JSON-LD, `srcset` и уже отрисованного DOM. Некоторые CDN требуют дополнительных cookie или токенов и могут отказать; закрытые или полностью динамические галереи могут не отдать фотографии. Тогда используйте ручную загрузку.
- Утилита работает только с публичными HTTP(S)-страницами и публичными IP-адресами. CAPTCHA, авторизация, блокировка площадки и другие ограничения не обходятся. В таком случае загрузите фотографии вручную.
- HTML объявления считается недоверенным содержимым. Утилита не исполняет текст объявления как инструкции и не вставляет исходный HTML в КП.
- Изображения скачиваются локально; HTML-шаблоны КП не загружают внешние картинки или скрипты.
- Пользователь отвечает за проверку содержимого и наличие прав использовать фото в коммерческом предложении.

Полный порядок подготовки и проверки КП описан в `PROMPT.md` и `STANDARD.md`.
